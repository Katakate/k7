Nodes labelled k7.katakate.org/node-pool=true are prepared by k7-node-installer;
a node takes sandboxes once it carries k7.katakate.org/node-ready:
  kubectl get nodes -L k7.katakate.org/node-ready
Smoke test (one sandbox per backend):
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --timeout 35m
Uninstall undoes node prep first (disks kept unless nodeInstaller.wipeDisks):
  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }} --timeout 35m
API keys (kubectl current context, or K7_KUBECONFIG):
  k7 --system-namespace {{ .Release.Namespace }} generate-api-key <name> --role admin
